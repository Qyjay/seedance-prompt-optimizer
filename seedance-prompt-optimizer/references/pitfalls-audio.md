# 音频类陷阱（A-1 ~ A-4）+ F-1 NSFW

---

## A-1 · 结尾噪音

**症状**：视频结尾，尤其有旁白时，出现"咔哒"一下的噪音或截断音。

**修复**：

- 出现概率不高，可**抽卡**重生。
- 或用**剪映**等工具的"音频包络线"功能，在末尾手动将音量平缓地降为 0（音频淡出）。

---

## A-2 · 中文发音不准

**症状**：特定字发音不准、多音字没发对正确读音。

**修复（轻量）**：把不常见字替换为**同音常用字**。

| 不准 | 改写 |
|---|---|
| 棪木 | 燕木 |
| 螭龙 | 吃龙 |
| 蒹葭 | 兼家 |

**修复（稳定）**：

1. 先用 TTS 工具生成准确音频。
2. 把音频转为黑屏视频。
3. 把黑屏视频作为参考视频输入：

```
参考@视频1（黑屏 TTS 视频）的音频，生成 [画面描述]，画面与音频严格对齐。
```

## A-3 · 音色参考不准

**症状**：参考了萌妹子音色，生成出来变成御姐；或参考了憨厚男童声，生成出来偏尖细；整体音色与参考音频出入较大。

**根本原因**：参考音频本身信息不足（时长太短、环境噪声、语速异常），模型无法从音频中准确提取音色特征；加上 prompt 中没有文字补充描述，模型只能"猜"。

**修复（双重锁定，缺一不可）**：

1. **在 prompt 音频绑定句中加入音色特征描述**（性别 + 年龄感 + 2-3 个声音质感词）：

```
[音频1]为角色"爱豆"的专属音色参考（活泼稚嫩的男童声，音调偏高、透亮有弹性），
本视频中所有由爱豆发出的台词,必须严格使用[音频1]的音色合成,禁止用于其他任何角色。

[音频2]为角色"卡皮皮"的专属音色参考（憨厚带点鼻音的男童声，语速稍慢、低沉圆润），
本视频中所有由卡皮皮发出的台词,必须严格使用[音频2]的音色合成,禁止用于其他任何角色。
```

2. **画内台词括号内同样附带音色描述**，双重锁定：

```
爱豆(画内,活泼稚嫩男童声,音色严格使用[音频1],禁止偏离[音频1]):{走呀!}
卡皮皮(画内,憨厚带鼻音男童声,音色严格使用[音频2],禁止偏离[音频2]):{别忘带上你的嗨皮表~}
```

3. **让台词文本风格与参考音频风格尽量接近**：活泼轻快的音频配活泼轻快的台词，低沉稳重的音频配相应语气的台词。

**常用音色描述词速查**：

| 类型 | 常用描述词 |
|---|---|
| 儿童 | 稚嫩透亮、活泼明亮、憨厚带鼻音、软糯甜美、奶声奶气 |
| 青少年 | 清脆爽朗、青涩略带沙哑、阳光向上 |
| 女性成人 | 温柔偏低沉、清甜细腻、爽利干脆、御姐低沉磁性 |
| 男性成人 | 醇厚低沉、沙哑磁性、明朗有力、沉稳干练 |

## A-4 · MV 解决方案

**症状**：生成视频中的音频与原本参考音频差别较大，导致口型对不上。

**修复**：

1. 把音频转成**黑屏视频**。
2. 让生成视频的长度跟输入视频**严格一致**。
3. 口型对齐成功率会极高。

```
@视频1（黑屏音频视频，时长 8秒）。
生成 [画面描述]，时长严格等于 8 秒，画面节奏跟随@视频1 的音频。
```

## F-1 · NSFW（海外）

**症状**：NSFW 场景不按提示词执行。

**说明**：当前模型内置了安全底线，会对 NSFW 内容进行改写，**与是否关闭 content filter 无关**。

**修复**：当前尽量避开直白的描述。模型会在近期更新——届时不再改写 NSFW，仅输出风险标记 tag。

---

## 通用音频建议

1. **台词语言统一**：避免中英混用（专有名词除外）。
2. **小语种台词必须标注语种**：

```
用日语说道{こんにちは}
用韩语说{아빠, 배고파요!}
```

3. **特殊字符规范**：音乐用 `()`、音效用 `<>`、台词用 `{}`、字幕用 `【】`。
4. **避免生僻字**，优先使用常用字。
