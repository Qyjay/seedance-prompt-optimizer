# 导演级方法论：剧组编排 + 时序分镜 + 提示词扩写

> 来源：火山引擎《Seedance 2.0 - PE 指南》"像导演一样创作"章节。

## 一、剧组编排（多模态素材角色分配）

Seedance 2.0 最强大的能力之一，是同时理解文字、图片、视频、音频，并允许通过 `[图N]/[视频N]/[音频N]` 为每种素材分配角色。

**思维升级**：从"拍一段视频" → "**导一幕戏**"。把准备的素材看作一个"剧组"，为它们分配四类核心角色：

### 1. 角色锚定（1-2 张图片）

**作用**：锁定角色外观，解决"我是谁"。

**最佳实践**：

- **强烈建议**提供两张图：**一张正面高清大头照** + **一张全身照**
- 这能极大保证角色在视频中的一致性
- 不要把脸图与姿态图、服装图、细节图混在一张图上（V-1）

**示例**：

```
[图1] 为角色"X"的面部特征参考（高清大头照）
[图2] 为角色"X"的服装与体型参考（全身照）
```

### 2. 场景定调（1 张图片）

**作用**：锁定环境氛围与美术风格，解决"我在哪"。

**示例**：

```
[图3] 为场景"咖啡店"的环境与美术风格参考，
严格还原暖色调木质家具、复古吊灯、靠窗座位布局。
```

### 3. 运镜参考（1 段视频）

**作用**：直接复刻镜头语言与动作节奏，解决"怎么动"。**这是学习复杂运镜的捷径**。

**示例**：

```
参考 [视频1] 的运镜方式（推拉摇移节奏），生成 [新场景] 的运镜，
保持运镜节奏与方向一致；画面内容不复刻 [视频1]。
```

### 4. 节奏氛围（1 段音频）

**作用**：控制情绪、音色或背景音乐，解决"什么感觉"。

**示例**：

```
[音频1] 为角色"X"的专属音色参考，本视频中所有由 X 发出的台词，
必须严格使用 [音频1] 的音色合成，禁止用于其他任何角色。
```

或：

```
（背景音乐参考 [音频2] 的节奏与情绪，温柔慢节奏钢琴曲）
```

### 剧组分配速查表

| 素材类型 | 角色 | 数量上限 | 关键约束 |
|---|---|---|---|
| 图片 | 角色锚定 | 2 张 / 角色（大头照 + 全身照） | 单独裁剪、不混杂 |
| 图片 | 场景定调 | 1 张 | 风格统一 |
| 图片 | 道具锚定 | 1 张 / 关键道具 | 显式定义"严格还原..." |
| 视频 | 运镜参考 | 1 段 | 明确"只参考运镜，不复刻内容" |
| 视频 | 动作参考 | 1 段 | 明确"参考动作细节" |
| 视频 | 特效参考 | 1 段 | 数字滚动 / 转场 / 粒子等不稳定特效必备 |
| 音频 | 音色绑定 | 1 段 / 角色 | 严格绑定到特定角色 |
| 音频 | 背景音乐 | 1 段 | 用 `()` 标注节奏氛围 |

> **总数上限**：单次生成参考素材总量 ≤ 4-5 个（V-18），超出建议拆段。

## 二、时间轴化分镜脚本

模型的内在逻辑是**基于时间解耦**的。最能产出电影感的 prompt，是 **"时间轴化分镜脚本"**。

你需要像导演一样，把一个长镜头拆解为多个逻辑连贯的短镜头。

### 反面案例（模糊不清）

> 一个男人在街头紧张地奔跑，他撞翻了水果摊，然后跳过墙消失了，整个过程很有电影感。

**问题**：

- "紧张"、"电影感"这类抽象词模型无法转化为可视参数
- 没有镜头切分，模型不知道哪个动作属于哪个景别
- 没有时间锚点，节奏完全交给模型自由发挥

### 正面案例（结构清晰）

```
镜头 1（0 至 5 秒）：
【中景】男人在狭窄的巷子里开始缓慢起跑，呼吸急促，
镜头手持微抖跟随。

镜头 2（5 至 10 秒）：
【近景 + 快速摇晃】男人惊慌地回头看，身体不小心撞翻路边的水果摊，
水果滚落一地。

镜头 3（10 至 15 秒）：
【全景 + 固定】男人快速跑向巷子尽头，翻过一道矮墙，
消失在画面外。镜头缓慢拉远。
```

**关键要点**：

| 要素 | 推荐写法 | 禁忌写法 |
|---|---|---|
| 时间锚点 | `镜头 1（0 至 5 秒）` ✅ | `0.3 秒后`、`1.7 秒时` ❌（亚秒级模型不稳定） |
| 景别 | 每镜单独标注【中景】【近景】 ✅ | 全程不标景别 ❌ |
| 运镜 | 每镜 1-2 种（手持跟随 / 摇晃 / 固定） ✅ | 一个镜头堆砌 5 种运镜 ❌ |
| 节奏 | 段级时间轴 + 自然语言串接 ✅ | `→` 箭头串接（模型可能渲染成画面元素） ❌ |
| 动作 | 按肢体先后顺序写 ✅ | 多动作并发、抽象描述 ❌ |

### 时长规划建议

| 总时长 | 推荐镜头数 | 每镜时长 |
|---|---|---|
| 4–5 秒 | 1 镜 | 单镜连续 |
| 6–8 秒 | 1–2 镜 | 每镜 3–4 秒 |
| 9–12 秒 | 2–3 镜 | 每镜 3–5 秒 |
| 13–15 秒（上限） | 3 镜 | 每镜 4–5 秒 |

> 镜头过多 → 每镜时长被压缩，动作不完整；镜头过少 → 长镜头中后段易胡言乱语 / 风格漂移。

## 三、提示词扩写与润色（LLM/VLM 辅助）

实际业务中很难做到完全贴合的创作要求。可依托 VLM 与 LLM 能力，搭建专属 AI 导演助手，辅助完成创作把控。

### 推荐工具链

| 工具类型 | 用途 | 备注 |
|---|---|---|
| **剧本导演 System Prompt** | 把用户口语化需求转为分镜脚本 | 火山引擎官方提供模板 |
| **一键生成电影级 Prompt** | 给定主题，输出八要素结构化 prompt | 公开方案，可参考 |
| **AI 视频生成 Prompt Design** | Skill 化的 prompt 设计能力 | 字节内部技能 |

### 自建专属导演助手的建议流程

1. **垂类沉淀**：选定 1-2 个固定业务场景（如儿童教育 / 影视短剧 / 广告营销）
2. **prompt 模板库**：把成功案例的 prompt 模板化，标注变量槽位
3. **VLM 反馈循环**：用 VLM 对生成视频做 5 维体检评分，反向优化 prompt
4. **持续迭代**：每周回顾失败案例，沉淀到 pitfalls 表

### 何时不要走 LLM 扩写

- 用户已经给出非常具体的画面（"红裙女孩第 3 秒侧身回头"）→ 直接套八要素公式即可
- 用户只是改写已有 prompt 中的 1-2 个细节 → 用 `+update --command str_replace` 思路逐字精修，不要整段重写
- 用户提供的参考素材已经把"剧组"分配完毕 → 直接组装，不用 LLM 创意发挥

## 四、剧组编排 + 时序分镜 完整组装示例

### 用户需求

> 帮我做一个 15 秒的视频：爱豆（卡通熊，棕色毛绒）和卡皮皮（粉色小猪）在家门口准备出门去超市。妈妈在画外提醒他们买菜。两个角色对话要用我给的音频音色。

### 素材清单

- [图1]：爱豆全身照（棕色毛绒、红色背带短裤、白T恤）
- [图2]：卡皮皮全身照（粉色短毛、蓝色围裙）
- [图3]：家门口场景图
- [音频1]：爱豆音色（活泼男童）
- [音频2]：卡皮皮音色（憨厚男童）

### 八要素 + 剧组 + 时序分镜组装

```
[图1] 为角色"爱豆"的外观参考，严格还原棕色毛绒质感、大眼圆脸、红色背带短裤+白T恤+橙色帆布鞋。
[图2] 为角色"卡皮皮"的外观参考，严格还原粉色短毛、圆润体型、蓝色围裙。
[图3] 为场景"家门口"参考，严格还原木质门框、暖色调玄关。
[音频1] 为角色"爱豆"的专属音色参考，本视频中所有由爱豆发出的台词，必须严格使用 [音频1] 的音色合成，禁止用于其他任何角色。
[音频2] 为角色"卡皮皮"的专属音色参考，本视频中所有由卡皮皮发出的台词，必须严格使用 [音频2] 的音色合成，禁止用于其他任何角色。

3D 皮克斯卡通动画风格，暖色调，治愈系儿童动画。

镜头 1（0 至 5 秒）：
【中景，平视】爱豆和卡皮皮一起站在家门口（参考 [图3]），爱豆右手扶门把，卡皮皮双手叉腰仰头看爱豆。
妈妈（30岁温柔女声，模型合成，不使用任何参考音频，画外）：{爱豆，去超市帮我买菜！}

镜头 2（5 至 10 秒）：
【近景，跟拍】爱豆缓慢转头朝卡皮皮，眼睛眯起笑。
爱豆（画内，音色严格使用 [音频1]，禁止偏离 [音频1]）：{走呀卡皮皮！}

镜头 3（10 至 15 秒）：
【中景，平稳侧方跟拍】两人并排向画面右侧走出，背景门框缓慢退后。
卡皮皮（画内，音色严格使用 [音频2]，禁止偏离 [音频2]）：{好嘞！}

3D 皮克斯卡通动画风格，暖色调，电影级渲染，画面治愈温馨。

4K 超高清、60fps 高帧率、HDR、细节丰富、无噪点、无模糊、电影质感。

保持无字幕，避免画面生成字幕；不要生成 logo，不要生成水印；视频全程不要在同一画面中复制相同人物，不要多人同脸；面部稳定不变形，五官清晰，人体结构正常，动作自然流畅不僵硬，无卡顿、无闪烁。

时长：15秒，比例：16:9
```

> 注意：
> 1. 素材按 prompt 出场顺序上传（[图1] [图2] [图3] [音频1] [音频2]）—— A-3 串台修复关键。
> 2. 妈妈无参考音频 → 明确"模型合成，不使用任何参考音频"，避免错绑 [音频1] 或 [音频2]。
> 3. 妈妈台词是画外音 → `(画外)` 标注，避免模型让爱豆嘴部动起来说妈妈的话。
> 4. 三个镜头按段级时间轴拆分，每镜 5 秒，节奏稳定。
