# 特殊字符与参数规范

## 一、特殊字符（强制）

Seedance 用特殊符号区分不同信息类型，使用不当会导致内容混淆或被忽略。

| 内容 | 符号 | 示例 |
|---|---|---|
| 音乐 | `（）` | `（背景中播放着快节奏的摇滚乐）` |
| 音效 | `<>` | `<远处传来狗叫声>` |
| 台词 | `{}` | `{你好，世界}` |
| 字幕 | `【】` | `【第一章：启程】` |

### 台词的小语种规则

非中英文台词必须标注语种：

```
用日语说道{こんにちは}
用韩语说{아빠, 배고파요!}
用法语说{Bonjour le monde}
```

### 错误示范

| ❌ 错误 | ✓ 正确 |
|---|---|
| `[背景：摇滚乐]` | `（背景中播放着快节奏的摇滚乐）` |
| `角色说："你好"` | `角色说{你好}` |
| `[第一章]` | `【第一章】` |

## 二、参数规范

时长和宽高比通过接口已可传，但建议在 prompt **最前面或最后面**也加上，效果更稳定：

```
时长：4秒，比例：9:16
```

### 关键约束

- **必须用中文"秒"**，不能写"s"、"seconds"、"sec"。
- 时长支持 4 / 5 / 6 / 8 / 10 / 12 / 15 秒等。
- 比例：`16:9` / `9:16` / `1:1` / `4:3` / `3:4`。

### 已知支持但旧版本可能异常的字符

`--` 双横线之前会导致不响应（V1.6 已修复）。其他不可见字符（如全角空格、零宽字符）建议尽量清理。

## 三、台词语言规范

- 台词语言必须**统一**（专有名词除外）。
- 不要中英混用，否则发音/口型容易出错（A-2、V-11）。

### 错误示范

```
角色说{这个 schedule 我们要 reschedule 一下}
```

### 正确示范（任选一种语言）

```
角色说{这个日程我们要重新安排一下}
角色用英语说{We need to reschedule this meeting}
```

## 四、数字与小语种发音（A-2）

中文发音不准时，把不常见字替换成同音常用字：

| 不准 | 改写后 |
|---|---|
| 棪木 | 燕木 |
| 螭龙 | 吃龙 |
| 蒹葭 | 兼家 |

或更稳的解法：先用 TTS 工具生成准确音频，再把音频转成黑屏视频作为参考输入（A-4）。
