# 终极手段：当一切方法失效时

> 来源：火山引擎《Seedance 2.0 - PE 指南》"终极手段：当一切方法失效时"。

## 何时启用

当你已经尝试了以下所有手段后，仍然无法达到预期效果：

- ✅ 八要素公式 + U 型布局
- ✅ 五维体检全部修复
- ✅ V-1 ~ V-18 / A-1 ~ A-4 全部排查
- ✅ 抽卡 ≥ 5 次
- ✅ 调整素材组合 ≥ 3 次
- ✅ 切换横竖屏 / 调整时长 / 拆分镜头

**仍未达标** → 不要陷入无尽的"玄学调参"。此时**最有效的方法是：寻求火山引擎 CSM（客户成功经理）的帮助**。

## CSM 求助清单（必须备齐）

为了让技术支持团队能最高效地定位问题，联系 CSM 时**必须**准备并提供以下两类信息：

### 1. 全部输入信息

- [ ] **完整 prompt 文本**（一字不漏，包括 `[图N]/[视频N]/[音频N]` 标注）
- [ ] **所有参考素材文件**：图片 / 视频 / 音频
- [ ] **API 调用 / 脚本**及所有传入参数（model_id、resolution、duration、aspect_ratio 等）
- [ ] **生成结果视频文件**（用于复现问题）

### 2. 模型返回的 `request_id`

- [ ] **request_id**：这是定位到该次具体生成任务的唯一标识
- 拥有 request_id，技术团队就能深入到模型内部，分析该次任务的具体运行状态和中间结果

## 求助模板（直接复制给 CSM）

```
您好 CSM，遇到 Seedance 2.0 生成异常需要技术支持，详情如下：

## 1. 业务背景
- 业务场景：[儿童教育 / 影视短剧 / 广告营销 ...]
- 业务目标：[本视频用于 ...]

## 2. 问题描述
- 主要症状：[ID 漂移 / 字幕乱出 / 数字滚动错乱 / ...]
- 五维体检命中：[ID稳定 ❌ / 画面稳定 ✅ / ...]
- 已尝试的修复手段：[列出按顺序尝试过的方法]
- 抽卡次数：[5 次仍未达标]

## 3. 完整输入

### 3.1 Prompt 文本
[贴完整 prompt，含所有 [图N] / [音频N] 等指代]

### 3.2 参考素材（按 prompt 出场顺序）
- 图片1：[文件名 / TOS URL]
- 图片2：[文件名 / TOS URL]
- 视频1：[文件名 / TOS URL]
- 音频1：[文件名 / TOS URL]

- model_id: doubao-seedance-2-0-...

## 4. request_id 列表
- 抽卡 1：req_xxxxxxxx

## 5. 生成结果
[贴 5 次抽卡的生成视频文件 / TOS URL]

## 6. 期望
[期望 CSM 协助分析：是否暗水印导致 / 是否需要定制 ep / 是否模型 bug / ...]
```

## 携带这些信息后

CSM 就能为你启动 **Case by Case** 的问题解决和效果优化流程，实现技术支持的精准闭环：

1. **问题定位**：通过 request_id 拉取模型内部运行日志
2. **方案输出**：可能给出定制 prompt 模板 / 切换 ep / 关闭暗水印 / 切换 model 版本
3. **闭环验证**：用新方案重新生成，验证良品率是否达标

## 如何获取 request_id

不同接入方式获取 request_id 的方法不同：

| 接入方式 | request_id 位置 |
|---|---|
| Volcano Ark API | 响应 header `X-Request-Id` 或 body `id` 字段 |
| 火山引擎控制台 | 任务详情页"任务 ID"字段 |
| 即梦 / 豆包 App | 客服反馈通道 / 联系 CSM 索取 |
| Asset 库 / Mira | 任务 metadata 中的 task_id 或 request_id |

## 在等待 CSM 反馈期间

不要停止业务，可以采取的临时方案：

1. **降级方案**：用 Seedance 1.0 / 其他模型的 fallback 输出
2. **后期补救**：用 AI MediaKit 字幕擦除、画面修复等工具修补
3. **业务协商**：与产品 / 运营协商是否可降低良品率要求或调整业务场景
4. **素材重制**：如怀疑参考素材本身质量不够，重新拍摄 / 处理素材

## 关键原则

> **不要在玄学调参中无限循环。设定一个止损线（例如抽卡 5 次或调整 prompt 3 轮）。达到止损线 → 立即走 CSM 求助流程。**

时间是最宝贵的资源。技术支持流程是火山引擎为客户提供的 **付费保障**，请合理使用。
