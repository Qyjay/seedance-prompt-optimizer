# 任务类型 · 参考 / 编辑 / 延长 / 组合

Seedance 2.0 的参考生视频场景下，任务必须先归到这 4 种之一。**判错任务类型 = prompt 直接失效**，因为不同任务用不同句式。

## 1. 参考（Reference）

**用途**：从素材中提取部分元素（主体、风格、场景、音效），生成一个**全新视频**。

**适用场景**：动作迁移、主体复用、氛围借鉴。

**推荐句式**：

- `参考<图片N>中的「主体N」，生成……`
- `参考<视频N>中的[动作/运镜/场景/风格/音效]，生成……`
- `参考<音频N>中的[音色]，生成……`

**示例**：

```
参考@图片1中的女子形象，生成她在一家咖啡店吃蛋糕的画面，暖色调、3D 国漫 CG 仙侠风格。
```

## 2. 编辑（Edit）

**用途**：在原视频基础上做局部或全局修改。**未明确说要改的部分，默认保持不变。**

**适用场景**：局部替换、主体抹除、属性修改。

**推荐句式**：

- `严格编辑<视频N>，将其中的[原特征]修改为[新特征]……`
- `删除<视频N>中的[X]，视频其他内容保持不变`
- `在<视频N>的[时间位置]+[空间位置]，增加[理想元素描述]`

⚠️ **绝对不要写"参考视频N"**！会被模型识别为参考任务，直接走错分支。

**示例**：

```
严格编辑@视频1，将其中的香水替换成@图片1中的面霜，动作和运镜不变。
```

## 3. 延长（Extend）

**用途**：在时间维度上延续原视频，要求音视频风格、主体、叙事保持一致。

**适用场景**：续写剧情、延展动作、补全片段。

**推荐句式**：

- `延长<视频N>，生成……`
- `向前/向后延长<视频N>，生成……`
- `生成<视频N>之前/之后的内容+[需延长的视频描述]`

⚠️ 同样**不要写"参考视频N"**。

⚠️ 模型会自动截取衔接部分，输入视频原有片段不会重复生成。

⚠️ **画质劣化（V-8）**：把模型生成的视频再延长，画质会劣化叠加。修复方式：先把原始视频用 Seedance 2.0 转化成**白模视频**，再作为输入视频，同时使用高清的人物图和场景图作为参考。

**示例**：

```
向前延长@视频1，给白衣男子过肩镜头，白衣男子说{It's not that bad. You're just stressed. Everyone goes through this.}
```

## 4. 组合任务

**用途**：需要"参考一个素材 + 编辑另一个素材"。

**推荐句式**：

```
参考<图片/视频N>的[参考维度]，严格编辑<视频X>，[具体编辑内容]
```

**示例**：

```
参考@图片1中的服装风格，严格编辑@视频1，将主角身上的西装替换为@图片1中的汉服，动作和运镜保持不变。
```

## 轨道补齐（特殊延长场景）

句式：`<视频1>+[过渡画面描述]+接<视频2>+[过渡画面描述]+接<视频3>`

⚠️ 限制：最多 3 段视频输入，**总时长不得超过 15 秒**。模型自动截取首尾视频的衔接部分。

**示例**：

```
@视频1，树叶落地的瞬间，激起金色粒子特效，一阵风吹过，接@视频2。
```

## 决策流程图

```
用户给了视频素材吗？
├─ 没有 → 参考（仅用图片/音频）或纯文生视频
└─ 有
   ├─ 想生成全新视频，只借素材里的元素 → 参考
   ├─ 想在视频上加/删/改东西 → 编辑
   ├─ 想续写或前补一段 → 延长
   ├─ 想串联多段视频 → 轨道补齐（≤3 段、≤15s）
   └─ 既要参考又要编辑 → 组合
```
