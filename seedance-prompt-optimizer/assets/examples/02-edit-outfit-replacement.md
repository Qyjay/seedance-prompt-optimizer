# 示例 2：视频编辑 — 模特换装（修复任务类型误用）

## 用户原始 Prompt

> 参考视频 1 里的模特，参考图 1 里的红裙子，把模特身上的衣服换成红裙子，其他不动。

## 附带素材

- 视频 1：模特走秀视频
- 图片 1：红色连衣裙商品图

## 🎯 诊断

- **任务类型**：编辑（Edit）— 用户误用了"参考视频"句式，会被识别成参考任务，导致整个视频重新生成而不是替换衣服
- **命中陷阱**：
  - 任务类型混淆：必须改用"严格编辑@视频1"句式，禁止"参考视频 1"
  - V-2 字幕：默认加反字幕约束
  - V-3 logo：商品类视频强烈建议加反 logo
- **关键修改点**：
  1. 句式改为"严格编辑@视频1"
  2. 明确"动作、运镜、场景全部保持不变"
  3. 加默认护栏

## ✅ 优化后的 Prompt

```
将@视频1 中的模特定义为「主体1」。

严格编辑@视频1，将「主体1」 身上的服装替换为@图片1 中的红色连衣裙。
要求：
- 模特动作、走位、表情完全保持不变
- 镜头、运镜、景别完全保持不变
- 场景背景、灯光、色调完全保持不变
- 仅替换服装

保持无字幕，避免画面生成字幕；不要生成 logo，不要生成水印。

时长：[与@视频1 时长一致]，比例：[与@视频1 比例一致]
```

## 📌 使用说明

- 素材输入顺序：视频1=模特走秀视频，图片1=红色连衣裙商品图
- 不要传入接口的时长 / 比例覆盖原视频
- 抽卡建议：如出现"动作变化、运镜变化"，在 prompt 中再补一句"严格保持原视频每一帧的动作和镜头位置"
