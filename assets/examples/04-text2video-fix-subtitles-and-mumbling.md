# 示例 4：多镜头叙事 + 字幕规避（修复字幕乱出 + 胡言乱语）

## 用户原始 Prompt

> 做一段抖音风格的 9:16 视频，5 秒一个场景，3 个场景一共 12 秒。男主在开会、然后走出公司、最后比心。要求有内心独白配音，不要字幕。但是我之前生成的总是出字幕，配音还说一些奇怪的话。

## 🎯 诊断

- **任务类型**：参考（含纯文生视频路径）
- **命中陷阱**：
  - V-2 字幕：竖屏 + 多镜头 + 配音 = 字幕高发组合（约 60–90%）
  - V-11 胡言乱语：竖屏 + 12 秒长时长容易触发胡言乱语
  - V-3 logo：抖音风格视频默认加反 logo
- **关键修改点**：
  1. **强烈建议改横屏 16:9**：字幕概率从 60–90% 降到 < 10%
  2. **缩短到 8 秒（3 段约 2.5 秒）**：胡言乱语率从 70% 降到 30%
  3. 显式加反字幕、反 logo
  4. 用"镜头 1 / 镜头 2 / 镜头 3"分段，不写"0–3 秒"
  5. 配音用 `{}` 包裹，避免被理解为字幕

## ✅ 优化后的 Prompt

```
高清手机实拍质感，抖音原生风格，纯净画面。

镜头 1：中景，会议室，主体1（穿白色衬衫的 28 岁中国职场男性）皱着眉低头看会议资料，手指无意识敲击桌面，背景同事虚化。
旁白VO：{完了，这个 PPT 还没改完，等下一定会被批评。}（青年男声，状态焦虑，语气压抑）

镜头 2：跟拍，主体1 推开公司大门走出写字楼，午后阳光正好洒在脸上。镜头从背后跟拍切换为侧拍中景。
旁白VO：{算了不想了，先去吃饭，活人不能让 PPT 憋死。}（语气逐渐放松）

镜头 3：近景，主体1 看向镜头，露出一个释然的微笑，双手在胸前缓慢比出一个心形，画面亮度微微提升。
旁白VO：{至少今天还活着，给自己点个赞。}（语气轻松、温暖）

风格：超写实，电影级渲染，自然光，浅景深。

（背景中播放着轻柔治愈的钢琴 BGM）

保持无字幕，避免画面生成字幕；不要生成 logo，不要生成水印；视频全程不要在同一画面中复制相同人物，不要多人同脸。

时长：8秒，比例：16:9
```

## 📌 使用说明

- **关键妥协**：把竖屏 9:16 改成横屏 16:9，可后期裁剪为竖屏。这一改动能让字幕生成概率从 60–90% 降到 < 10%。
- **关键妥协**：把 12 秒缩短到 8 秒（3 段约 2.5 秒），降低胡言乱语率。
- 抽卡建议：
  - 如果仍出现字幕，把 prompt 末尾再加一句"画外音不生成字幕"，并去除参考素材中的所有文字。
  - 如果配音仍然胡言乱语，缩短到 6 秒、把配音从 3 段并为 1 段。
- 如果客户坚持竖屏 9:16，提前向客户说明：字幕概率会高 1 倍以上，需要后期擦除工具兜底。
