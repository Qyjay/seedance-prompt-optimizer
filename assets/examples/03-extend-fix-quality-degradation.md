# 示例 3：视频延长 — 修复画质劣化与衔接跳变

## 用户原始 Prompt

> 我之前用 Seedance 生成了一段 5 秒视频，参考视频续写一段 5 秒，让主角继续走，但是续写后画质变得很糊，衔接处还会跳一下。

## 附带素材

- 视频 1：之前用 Seedance 生成的 5 秒主角行走视频
- 图片 1：高清人脸特写图（用户暂未提供，建议补充）
- 图片 2：高清场景图（用户暂未提供，建议补充）

## 🎯 诊断

- **任务类型**：延长（Extend）— 用户误用"参考视频续写"，会走错分支
- **命中陷阱**：
  - V-8 视频延长画质劣化：原始视频是模型生成的，延长会导致画质叠加劣化（人脸出现斑驳色块）
  - V-6 衔接处跳变：延长模式衔接处常见画面跳变 → 后期需删 6+1 帧或转场切镜
  - 任务类型混淆：禁止"参考视频"
- **关键修改点**：
  1. 句式改为"向后延长[视频1]"
  2. 把[视频1] 先转化为白模视频再作为输入（修复 V-8）
  3. 同时输入高清人脸特写图 + 场景图
  4. 提示后期处理（删 6 帧 + 1 帧 或 转场切镜）

## ✅ 优化后的 Prompt（两步走）

### 第一步：先把[视频1] 转成白模视频

```
将[视频1] 转化为白模视频：保留所有人物的姿态、动作、走位与节奏，但移除所有纹理、色彩、面部细节，仅保留白色 3D 几何模型，背景纯白，光照均匀。

时长：5秒，比例：[与[视频1] 一致]
```

得到的输出记为 [视频2]（白模视频）。

### 第二步：基于白模视频做延长

```
向后延长[视频2]（白模视频）。

将[图1]（高清人脸特写）和[图2]（高清场景图）中的人物定义为「主体1」。「主体1」 的面部特征严格参考[图1]。场景严格参考[图2] 的色调、光影与建筑结构。

延长内容：「主体1」 继续向前走，节奏与[视频2] 末尾一致；走过 3 步后停下，缓慢转头看向画面右侧，眼神中带一丝迟疑，然后再次迈步前行。

风格：电影级渲染，超写实，暖色调，浅景深。

保持无字幕，避免画面生成字幕；不要生成 logo，不要生成水印。

时长：5秒，比例：[与[视频1] 一致]
```

## 📌 使用说明

- 素材输入顺序：视频2=白模视频（先生成），图片1=高清人脸特写，图片2=高清场景图
- **强烈建议用户额外提供高清人脸特写和场景图**——只用白模视频 + 原始低清场景图，画质会次于此方案
- **后期补救衔接跳变**：
  - 方案 A：用剪映对前段（[视频1]）末尾删 6 帧，对延长段开头删 1 帧
  - 方案 B：在 prompt 末尾加"以一次切镜结束本段"，用切镜代替无缝衔接
- 抽卡建议：连续延长不超过 2 次，每次延长后都用白模流程重新走一遍，避免画质叠加劣化
