# 示例 1：单人参考 + 古风短剧（修复 ID 漂移）

## 用户原始 Prompt

> 帮我做个古装视频，主角是个白衣公子，参考我给的人物三视图，他在庭院里舞剑，要超酷。3 秒。

## 附带素材

- 图片 1：人物三视图（正面 + 侧面 + 背面）
- 图片 2：庭院背景图

## 🎯 诊断

- **任务类型**：参考（Reference）
- **命中陷阱**：
  - V-1 ID 漂移：用户给的是三视图，人脸占比小 → 必须裁剪人脸特写
  - V-7 双胞胎风险：单人 + 多视图，强烈建议加反双胞胎护栏
  - V-4 风格漂移：未指定风格，古装容易跑偏成写实 → 加"3D 国漫 CG 仙侠风格"
  - V-2 字幕：默认加反字幕约束
  - V-3 logo：默认加反 logo 约束
- **关键修改点**：
  1. 让用户额外提供一张人脸特写图（图片 3），放在 prompt 最前面引用
  2. 主体定义 + 分层指代（面部 vs 妆造）
  3. 明确风格 + 反双胞胎 + 反字幕 + 反 logo 全套护栏

## ✅ 优化后的 Prompt

```
中景平视开场，镜头缓慢推进至近景。

将[图1]（三视图）和[图3]（人脸特写图）中的"白衣长袍、束发玉冠、剑眉星目的青年公子"定义为「主体1」。主体1 的面部特征严格参考[图3]（大头照），妆造与体型参考[图1]（三视图）。

镜头 1：中景，主体1 立于[图2] 的青砖庭院石阶上，左手持剑鞘，右手缓慢拔出长剑，剑身发出寒光。
镜头 2：环绕镜头，摄影机以主体1 为中心顺时针环绕一周，主体1 同时挥剑划出一道弧光，长袍随风飘起。
镜头 3：抽离式后拉运镜，从主体1 的面部特写持续后拉，逐步揭示整个庭院的全景，主体1 收剑入鞘，定格于画面中央。

3D 国漫 CG 仙侠风格，电影级渲染，暖色调，浅景深。

<金属拔剑出鞘的清脆声><剑风划过的破空声>（背景中播放着古风琵琶 BGM，节奏由缓到急再归于平静）

保持无字幕，避免画面生成字幕；不要生成 logo，不要生成水印；视频全程不要在同一画面中复制相同人物，不要多人同脸。

时长：3秒，比例：16:9
```

## 📌 使用说明

- 素材输入顺序：图片1=三视图，图片2=庭院背景图，**图片3=人脸特写图（必须新增）**
- 时长：3 秒，比例：16:9（横屏字幕概率更低）
- 抽卡建议：如仍出现 ID 漂移，把 prompt 中"严格参考[图3]"前置到主体定义最前面，并删除三视图只保留人脸特写 + 一张全身图。
