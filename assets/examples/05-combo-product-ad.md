# 示例 5：组合任务 — 多素材广告短片（参考 + 编辑）

## 用户原始 Prompt

> 我有一段我们去年拍的产品视频（一个保温杯在白色桌面上的旋转展示），还有一张今年新品保温杯的图片，还有一张品牌 logo 图。帮我做一个新品的产品视频，运镜跟去年那个一样，杯子换成新的，结尾要出我们的 logo，5 秒。

## 附带素材

- 视频 1：去年的保温杯 360 旋转视频
- 图片 1：新品保温杯产品图
- 图片 2：品牌 logo 图

## 🎯 诊断

- **任务类型**：组合（参考@视频1 的运镜 + 严格编辑/重生成画面 + Logo 演绎）
- **命中陷阱**：
  - V-3 logo：用户主动要 logo，但仍要避免出现其他平台 logo
  - V-2 字幕：广告视频默认加反字幕约束
  - 风格保持：产品广告需要明确"高清白底商品摄影"风格，否则容易跑偏
- **关键修改点**：
  1. 句式：参考@视频1 的运镜 + 主体替换为@图片1 + 结尾接@图片2 logo
  2. 主体严格定义为新品保温杯
  3. 风格关键词明确：白底、高清商品摄影
  4. logo 出现位置和方式明确

## ✅ 优化后的 Prompt

```
中景平视环绕镜头，背景为纯白工作室。

将@图片1 中"哑光银色金属机身、磨砂质感、金色 logo 的保温杯"定义为「主体1」。

参考@视频1 的运镜（摄影机以保温杯为中心顺时针 360 度环绕一周，主体始终居中），将主体替换为「主体1」。
镜头 1：中景特写，「主体1」 静止悬浮于白色桌面上方。
镜头 2：摄影机顺时针 360 度环绕「主体1」 一周，依次清晰展示其正面、侧面、背面。光线柔和均匀，无投影。
镜头 3：环绕结束后，画面缓慢淡出至纯白，浮现@图片2 的品牌 logo（金色，居中，由暗到亮渐显）。

风格：高清白底商品摄影，电影级渲染，浅景深。

保持无字幕，避免画面生成字幕；不要生成除@图片2 外的任何 logo，不要生成水印。

时长：5秒，比例：16:9
```

## 📌 使用说明

- 素材输入顺序：视频1=去年保温杯旋转视频，图片1=新品保温杯图，图片2=品牌 logo
- 时长：5 秒，比例：16:9
- 抽卡建议：
  - 如果运镜与去年视频不一致，在 prompt 中再补一句"严格保持@视频1 的环绕速度和方向"
  - 如果 logo 在视频中提前出现（不是结尾），在 prompt 中明确"@图片2 的 logo 仅在视频最后 1 秒出现"
- 如果客户希望横屏 + 竖屏两版，可分别生成（比例改 9:16），但建议主版用 16:9。
