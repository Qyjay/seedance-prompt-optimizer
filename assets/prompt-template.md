# Prompt 骨架模板

把以下 `[…]` 占位符替换为实际内容，即可得到一个符合 Seedance 2.0 最佳实践的 prompt。

---

## 基础骨架（适用于所有任务类型）

```
[镜头语言：景别 + 角度 + 运镜方法]。

将 [图1] 中的[2–3 个稳定特征]定义为「主体1」。
（如有多主体，逐一定义）

[动作 / 表情 / 空间变化按时间顺序描述。允许"镜头 1 / 镜头 2"分段]

[参考素材指代：使用 [图N]/[视频N]/[音频N]；参考/提取/结合 [图N] 中的[元素]，保持[元素]特征一致]

[风格美学：3D 国漫 CG 仙侠风格 / 2D 日漫风格 / 皮克斯 3D / …]

（[音乐]）<[音效]>[角色]说{[台词]}【[字幕]】

保持无字幕，避免画面生成字幕；不要生成 logo，不要生成水印；视频全程不要在同一画面中复制相同人物，不要多人同脸。

时长：[N]秒，比例：[16:9 / 9:16 / 1:1]
```

---

## 任务类型句式速查

### 参考（Reference）

```
参考 [图N] 中的[元素]，生成 [画面描述]
参考 [视频N] 的[动作/运镜/特效]，生成 [画面描述]
```

### 编辑（Edit）— 不要写"参考视频 N"

```
严格编辑 [视频N]，将其中的[原特征]修改为[新特征]
删除 [视频N] 中的[X]，视频其他内容保持不变
在 [视频N] 的[时间位置][空间位置]，增加[新元素]
```

### 延长（Extend）— 不要写"参考视频 N"

```
向后延长 [视频N]，生成 [新内容]
向前延长 [视频N]，生成 [新内容]
生成 [视频N] 之后的内容，[新内容]
```

### 组合

```
参考 [图N] 的[元素]，严格编辑 [视频X]，[具体编辑内容]
```

### 轨道补齐（≤3 段、≤15 秒）

```
[视频1] +[过渡画面]+ 接 [视频2] +[过渡画面]+ 接 [视频3]
```

---

## 限制条件库（按需追加）

| 场景 | 追加内容 |
|---|---|
| 默认 | `保持无字幕，避免画面生成字幕；不要生成 logo，不要生成水印` |
| 单人参考（防双胞胎） | `视频全程不要在同一画面中复制相同人物，不要多人同脸` |
| 风格易漂移 | `严格保持 [目标风格]，不要生成写实风格` |
| 数字人 / 口播 | `口型严格贴合台词，避免胡言乱语和重复台词` |

---

## 参数（必加）

```
时长：4秒，比例：16:9
```

⚠️ 必须用中文"秒"，不能写"s"。
