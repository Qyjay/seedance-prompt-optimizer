# 镜头语言：景别 · 角度 · 运镜

写镜头语言时按 **"景别 + 角度 + 运镜方法"** 三段组装。

## 一、景别（Shot Size）

| 景别 | 含义 | 典型用途 |
|---|---|---|
| 大远景 | 强调环境空间、人物渺小 | 史诗、空镜、地理交代 |
| 远景 | 完整人物 + 较多环境 | 人物与环境关系 |
| 全景 | 人物完整、占画面主体 | 动作、群像 |
| 中景 | 膝盖以上 / 腰部以上 | 对话、表演 |
| 近景 | 胸部以上 | 表情、情绪 |
| 特写 | 头部 / 局部 | 强情绪、细节 |

## 二、镜头角度

| 角度 | 含义 | 情绪效果 |
|---|---|---|
| 平拍 | 与人物视线齐平 | 客观、平等 |
| 仰拍 | 由下往上 | 突出权威、压迫感、英雄气场 |
| 俯拍 | 由上往下 | 渺小、脆弱、上帝视角 |
| 过肩 | 从一人肩后拍另一人 | 对话、第三方观察感 |

## 三、基础运镜

| 运镜 | 含义 |
|---|---|
| 推 | 摄像机向主体靠近 |
| 拉 | 摄像机离主体远去 |
| 摇 | 镜头方向左右/上下旋转 |
| 移 | 摄像机平行移动 |
| 跟拍 | 摄像机随主体移动 |
| 环绕 | 摄像机围绕主体旋转 |

## 四、其他常用效果

- **固定镜头**：摄像机不动。
- **手持镜头**：轻微抖动，写实/纪录感。
- **慢镜（慢动作）**：高帧率拍摄、放慢回放，强情绪。
- **快切**：多个短镜头快速切换，强节奏。

## 五、电影级运镜（10 种）

### 1. 正反打（Shot/Reverse Shot）

**定义**：对话场景的镜头切换技法。镜头 A 从人物 A 的过肩视角拍 B，镜头 B 从 B 的过肩视角拍 A，反复交替。摄影机始终在对话双方的轴线一侧（180 度原则），不越轴。

**变体**：

| 变体词 | 说明 | 适用场景 |
|---|---|---|
| 过肩正反打 | 标准用法，前景保留对方肩膀 | 常规对话 |
| 纯正反打 | 不保留肩膀，直接切对方面部特写 | 强调表情、激烈争吵 |
| 双人全景 + 正反打 | 先给全景确立空间，再切入正反打 | 开场对话 |
| 慢切正反打 | 较长时间停留再切换 | 文艺片、深刻对话 |
| 快切正反打 | 快速频繁切换 | 争吵、辩论、紧张谈判 |

**Prompt 范式**：

```
律师@图片1和嫌犯@图片2在审讯室对坐，标准过肩正反打对话，镜头在两人之间交替切换，冷蓝色灯光，悬疑氛围。
律师：{你当晚到底去过现场没有？}
嫌犯：{我根本没去过。}
…（连续对话）
```

### 2. 希区柯克眩晕变焦（Dolly Zoom）

**定义**：摄影机向前推进（Dolly in）同时向后变焦（zoom out），保持主体在画面中大小不变，但**背景产生强烈的空间压缩 / 拉伸变形**，制造眩晕感。

**情绪**：精神崩溃、悬疑惊悚、空间扭曲。

**Prompt 范式**：

```
主体在惊恐时希区柯克变焦，主体大小不变但背景强烈压缩拉伸。
```

### 3. 迈克尔贝环绕（Michael Bay 360 Hero Shot）

**定义**：摄影机以高速环绕主体旋转，主体始终在画面中心，配合低角度仰拍，强化主角英雄气场。

**技术要点**：运镜方向与拍摄对象方向相反；保持主体居中；建议 50fps 以上。

**Prompt 范式**：

```
迈克尔贝 360 度环绕镜头，低角度仰拍，主体始终居中，背景高速旋转，主角英雄气场。
```

### 4. 库布里克凝视（Kubrick Stare）

**定义**：对称构图 + 静止运镜，人物头部微低、眼神向上凝视镜头，构图严格对称，制造心理压迫感与异常感。

**Prompt 范式**：

```
库布里克对称凝视镜头，固定机位正面平拍，人物处于画面正中央，头部微低，眼神由下向上凝视镜头，背景严格对称构图，冷峻氛围。
```

### 5. 昆汀快速变焦（Crash Zoom）

**定义**：从远景或中景在极短时间内快速 zoom in 到特写，强调发现、惊讶、戏剧性瞬间。常配合突然的音效。

**Prompt 范式**：

```
快速变焦推镜（Crash Zoom），从中景在 0.3 秒内推到面部特写，配合<刀剑出鞘的金属声>。
```

### 6. FPV 穿越机运镜（First-Person View Drone Shot）

**定义**：穿越机第一视角，连续穿越多个空间，速度快、机动性强，画面具有强烈的沉浸感与连贯感。

**Prompt 范式**：

```
FPV 穿越机视角，镜头连续穿越[场景 1]→[场景 2]→[场景 3]，速度极快，画面流畅无切镜，沉浸式第一视角。
```

> ⚠️ **第一人称的完整方法论请看 `references/first-person-pov.md`**。任何涉及"第一人称 / POV / 主观镜头 / GoPro / 行车记录仪 / 沉浸视角"的需求都必须套用六要素骨架，而不是只写"第一人称视角"几个字（会触发漂回第三人称的陷阱 V-12）。FPV 只是第一人称的子类型之一，另外两类是 POV（主观镜头）和 Orb（一镜到底动作 POV）。

### 7. 子弹时间（Bullet Time）

**定义**：主体动作慢放至接近静止，摄影机围绕主体高速环绕，时空冻结感。

**Prompt 范式**：

```
子弹时间运镜，主体动作慢放接近静止，摄影机以 360 度高速环绕主体，时间冻结，背景模糊。
```

### 8. 长镜头（One Shot / Long Take）

**定义**：一镜到底，无切镜，镜头连续跟随主体或场景变化。

**Prompt 范式**：

```
一镜到底长镜头，镜头跟拍主体从[起点]→[中段]→[终点]，无切镜，连贯流畅。
```

### 9. 荷兰角倾斜（Dutch Angle）

**定义**：摄影机左右倾斜（一般 15–30 度），画面斜置，营造不安、混乱、心理失衡感。

**Prompt 范式**：

```
荷兰角倾斜镜头，画面向左倾斜约 20 度，主体处于不平衡状态，制造不安与紧张感。
```

### 10. 抽离式后拉运镜（Pull-Out Shot）

**定义**：镜头从特写或近景持续后拉，逐步揭示更广阔的场景与上下文，常用于结尾揭示、情绪释放。

**Prompt 范式**：

```
抽离式后拉运镜（Pull-Out），从主体面部特写持续后拉，依次揭示房间、建筑、城市、宇宙，配合舒缓 BGM。
```

## 六、组合用法

允许在一段 prompt 里组合多种运镜，按"镜头 1 / 镜头 2"分段：

```
镜头 1：中景平视固定镜头，主体1 进入画面。
镜头 2：快速变焦（Crash Zoom）推到主体1 的面部特写，配<刀剑出鞘声>。
镜头 3：360 度环绕主体1，背景高速旋转。
镜头 4：抽离式后拉镜头，逐步拉远至全景，画面定格。
```

⚠️ 注意：使用"镜头 1 / 镜头 2"做时序顺序是稳定的，**不要写"0–3 秒"** 这种精确时间。
