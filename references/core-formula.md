# 核心公式：八要素万能公式（PE 指南权威版本）

> 火山引擎官方 PE 指南：撰写 prompt 时尽量包含以下八个核心要素，能极大提升模型对指令的理解准确率。

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质参数 + 约束条件
```

公式逻辑：

1. **先锁定**："谁"（主体）在"干什么"（动作）
2. **再交代**："在哪"（场景）以及"氛围如何"（光影色调）
3. **然后告诉模型**："怎么拍"（镜头运镜）
4. **最后用**："风格、画质和约束"来收紧和规范最终输出

## 八要素详细字段

| 要素 | 核心要点 | 示例 |
|---|---|---|
| **精准主体** | 拒绝模糊，用"核心属性+外观特征+状态"定义。这是权重最高的指令。 | `一位20岁东亚淡颜女生，黑长直齐肩发，身穿白色棉麻连衣裙，赤足...` |
| **动作细节** | 写清动作的先后顺序、速度、幅度，避免单点、剧烈的动作。 | `...缓慢向前走，手臂自然摆动，发丝随海风轻柔扬起。` |
| **场景环境** | 写清时间、地点、环境细节，构建画面空间。 | `...站在黄昏时分的沙滩上，背景是橙紫色的日落天空和礁石。` |
| **光影色调** | 不用"氛围感"，用具体的光线类型、明暗效果、色彩倾向。 | `整体为逆光，在主角身上形成金色的轮廓光，色调温暖饱和。` |
| **镜头运镜** | 每段只用 1-2 种运镜，新手首选"近景 + 慢推"、"中景 + 跟拍"。 | `中景构图，平稳侧方跟拍镜头。` |
| **视觉风格** | 风格词单一，避免"复古"+"赛博朋克"混用。 | `电影质感，复古胶片风格，颗粒感明显。` |
| **画质参数** | 所有场景通用，可直接复制粘贴。 | `4K 超高清、60fps 高帧率、HDR、细节丰富、无噪点、无模糊。` |
| **约束条件** | 极其重要，尤其是人像场景，用于规避常见问题。 | `面部稳定不变形，五官清晰，人体结构正常，动作自然流畅不僵硬，无卡顿、无闪烁。` |

## U 型注意力机制下的组装节奏

Seedance 2.0 的注意力呈 **U 型** —— 开头与结尾权重最高，中间最低。八要素必须按以下三段布局：

### 首部（开头权重区，必抓）

- **素材定义**：`[图1]为角色"X"的外观参考,严格还原...`、`[音频1]为角色"X"的音色参考...`
- **精准主体**：核心属性 + 外观特征 + 状态
- **关键参考指代**：`参考 [图N] 中的「主体N」...`
- **风格关键词**：单一明确的风格词（如"3D 国漫 CG 仙侠风格"）

### 中部（叙事区）

按"**镜头 1（0 至 5 秒）/ 镜头 2（5 至 10 秒）/ 镜头 3（10 至 15 秒）**"的段级时间轴拆分，每镜内嵌：

- 动作细节（按肢体顺序，包含速度/幅度）
- 场景环境（时间、地点、关键元素）
- 光影色调（光源类型 + 方向 + 整体色调）
- 运镜（景别 + 1-2 种核心运镜）
- 画内/画外台词（按规范音色绑定）

⛔ 禁止亚秒级精确时刻（"0.3 秒后"、"1.7 秒时"），模型不稳定。

### 尾部（结尾权重区，必抓）

- **视觉风格收束**：再次重申风格关键词
- **画质参数模板**：`4K 超高清、60fps 高帧率、HDR、细节丰富、无噪点、无模糊、电影质感`
- **约束条件四件套**：
  1. 反字幕：`保持无字幕，避免画面生成字幕`
  2. 反 logo/水印：`不要生成 logo，不要生成水印`
  3. 反双胞胎：`视频全程不要在同一画面中复制相同人物，不要多人同脸`
  4. 反变形：`面部稳定不变形，五官清晰，人体结构正常，动作自然流畅不僵硬，无卡顿、无闪烁`
- **时长比例**：`时长：x秒，比例：x:x`（必须用"秒"，不能写"s"）

## 槽位说明（八要素拆解）

### 要素 1 · 精准主体（必须，开头放）

涉及参考素材里的主体时，**第一次出现就显式定义**：

```
[图N]为角色"角色名"的外观参考,严格还原[特征列表]
[图N]为关键道具"道具名"参考,严格还原[特征列表]
```

之后每次提到该主体都重复角色名，禁止省略指代。详见 `multimodal-referencing.md`。

### 要素 2 · 动作细节（必须，中部）

按时间顺序写。要求：

- 细化到肢体（手、腿、头部）
- 补充程度（幅度 / 速度 / 力度）
- 顺序按事件发生的先后，先主后次
- 允许"镜头 1 / 镜头 2"段级时序，**不要写"0.3 秒""1.7 秒"** 亚秒级时刻
- ⛔ 不要用 `→` 串接 beat（模型可能渲染成画面元素），用自然语言或"先...再...最后..."

### 要素 3 · 场景环境（中部）

时间 + 地点 + 关键环境元素。例如：`黄昏时分的沙滩上，背景是橙紫色的日落天空和礁石`。

### 要素 4 · 光影色调（中部）

具体词汇描述：光源类型 + 光线方向 + 整体色调。

- ⛔ 模糊词：`氛围感`、`高级感`、`电影感`
- ✅ 可视参数：`逆光 + 金色轮廓光 + 暖饱和色调 + 浅景深 + 35mm 胶片颗粒`

### 要素 5 · 镜头运镜（中部）

景别 + 角度 + 运镜方法（每段 1-2 种）。详见 `camera-language.md`。

- 景别：特写 / 近景 / 中景 / 全景 / 远景 / 大远景
- 角度：仰拍 / 俯拍 / 平拍 / 过肩
- 基础运镜：推 / 拉 / 摇 / 移 / 跟拍 / 环绕
- 电影级运镜：正反打 / Dolly Zoom / Michael Bay 360 / Kubrick Stare / Crash Zoom / FPV / Bullet Time / Long Take / Dutch Angle / Pull-Out

### 要素 6 · 视觉风格（结尾区附近）

明确的风格关键词，避免风格漂移与混用。详见 `style-aesthetics.md`。

常用：3D 国漫 CG 仙侠风格、2D 日漫风格、皮克斯 3D 动画、新海诚清新治愈、毛毡/粘土/水墨/赛博朋克、电影级渲染、超写实、巴洛克。

### 要素 7 · 画质参数（结尾区，可直接复制）

```
4K 超高清、60fps 高帧率、HDR、细节丰富、无噪点、无模糊、电影质感
```

### 要素 8 · 约束条件（结尾区，必加）

人像场景四件套：

1. **反字幕**：`保持无字幕，避免画面生成字幕`
2. **反 logo/水印**：`不要生成 logo，不要生成水印`
3. **反双胞胎**：`视频全程不要在同一画面中复制相同人物，不要多人同脸`
4. **反变形**：`面部稳定不变形，五官清晰，人体结构正常，动作自然流畅不僵硬，无卡顿、无闪烁`

参数：`时长：x秒，比例：x:x`

## 完整组装示例

### 输入（用户原 prompt，混乱版）

> 帮我生成一个视频：穿红裙子的女生在咖啡店吃蛋糕，参考我给的图，要可爱一点，要 3D 风，5 秒。

### 输出（U 型布局 + 八要素结构化版）

```
[图1]为角色"女子"的外观参考,严格还原穿红色连衣裙、戴草帽、20岁东亚淡颜的形象。

3D 国漫 CG 写实风格，电影级渲染。

镜头 1（0 至 3 秒）：中景，平视，镜头从女子正面缓慢推进至近景。女子坐在暖色调的咖啡店窗边，左手轻托脸颊微笑，右手用银色叉子叉起一块草莓蛋糕慢慢送入口中，眼神温柔，嘴角微微上扬。窗外午后暖阳透过玻璃洒在她的脸上形成柔和的轮廓光，色调温暖饱和，桌面上有一杯拿铁。

镜头 2（3 至 5 秒）：近景特写，镜头微微下摇，聚焦女子嘴角与蛋糕，浅景深背景虚化为暖橘色光斑。

参考 [图1] 中的"女子"，保持面部、服饰特征一致。

（背景中播放着轻柔的爵士钢琴曲）

3D 国漫 CG 写实风格，暖色调，电影级光影渲染，画面温馨治愈。

4K 超高清、60fps 高帧率、HDR、细节丰富、无噪点、无模糊、电影质感。

保持无字幕，避免画面生成字幕；不要生成 logo，不要生成水印；视频全程不要在同一画面中复制相同人物，不要多人同脸；面部稳定不变形，五官清晰，人体结构正常，动作自然流畅不僵硬，无卡顿、无闪烁。

时长：5秒，比例：16:9
```

## 排序优先级（U 型布局速查）

| 区域 | 内容 | 优先级 |
|---|---|---|
| 开头权重区 | 素材定义 + 精准主体 + 关键参考指代 + 风格词 | ⭐⭐⭐⭐⭐ |
| 中间叙事区 | 镜头 1 / 2 / 3 段级分镜（动作 + 场景 + 光影 + 运镜 + 台词） | ⭐⭐⭐ |
| 结尾权重区 | 视觉风格收束 + 画质参数 + 约束四件套 + 时长比例 | ⭐⭐⭐⭐⭐ |

> 关键原则：把"模型最容易忽略的全局约束"放结尾；把"必须严格执行的身份与素材绑定"放开头。中间区域填充叙事细节。
