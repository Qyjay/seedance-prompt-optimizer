# 一页纸提示词写作自查清单

> 来源：火山引擎《Seedance 2.0 - PE 指南》。每次写完 prompt，逐项检查，确保"指令"清晰、完整、无歧义。

## ✅ Seedance 2.0 Prompt 一页纸自查清单

### 准备阶段

- [ ] **核心目标**：我希望这条视频传递什么核心信息或情绪？（一句话总结）
- [ ] **参考素材**：是否准备好"剧组"四类角色（角色锚定 / 场景定调 / 运镜参考 / 节奏氛围）？
- [ ] **素材数量**：单次参考素材总量是否 ≤ 4-5 个？人物数量是否 ≤ 4 人？（V-18）
- [ ] **素材排序**：素材是否按 prompt 中出场顺序准备好？（A-3 防串台）

### 提示词撰写阶段（八要素检查）

- [ ] **精准主体**：是否清晰描述了核心人物 / 物体的（年龄/身份 + 外观/服装 + 状态/表情）？
- [ ] **动作细节**：动作是否有（起始 + 过程 + 结束）的连贯描述？是否明确了（速度/幅度）？
- [ ] **场景环境**：是否交代了具体的（时间 + 地点 + 关键环境元素）？
- [ ] **光影色调**：是否用了具体的词汇描述（光源类型 + 光线方向 + 整体色调）？
       例：午后斜阳 / 霓虹灯反射 / 冷蓝色调 / 逆光+金色轮廓光
- [ ] **镜头运镜**：是否为每个镜头指定了（景别 + 运镜方式）？（一个镜头只用 1-2 种核心运镜）
- [ ] **视觉风格**：是否给出了一个明确的、单一的风格词？
       例：日系清新 / 赛博朋克 / 国风水墨 / 3D 皮克斯
       ⛔ 避免混用："复古" + "赛博朋克" 同时出现
- [ ] **画质参数**：是否加入了 "4K 超高清、60fps 高帧率、HDR、细节丰富、无噪点、无模糊、电影质感" 模板？
- [ ] **约束条件**：是否加入了反字幕 / 反 logo / 反双胞胎 / 反变形四件套？

### 多模态与结构化

- [ ] **指代规范**：是否用 `[图N]` / `[视频N]` / `[音频N]` 统一格式？（不能用 Asset 库 ID 替代）
- [ ] **主体定义**：每个素材第一次出现时，是否显式定义？
       例：`[图1]为角色"X"的外观参考,严格还原...`
- [ ] **角色重复**：之后每次提到角色，是否重复角色名（禁止省略指代）？
- [ ] **音色绑定**：音频是否绑定到特定角色？画外台词是否标注"模型合成,不使用任何参考音频"？
- [ ] **台词格式**：画内 `角色名(画内,音色严格使用[音频N],禁止偏离[音频N]):{台词}` / 画外 `角色名(描述,画外):{台词}` ？
- [ ] **分镜结构**：是否用"镜头 1（0至5秒）/ 镜头 2（5至10秒）/ 镜头 3（10至15秒）"段级时间轴？
       ⛔ 不写"0.3秒后""1.7秒时"亚秒级
- [ ] **特殊符号**：音乐 `()` / 音效 `<>` / 台词 `{}` / 字幕 `【】`？小语种是否标注语种？

### U 型注意力布局检查

- [ ] **开头权重区**：素材定义 + 精准主体 + 关键参考指代 + 风格词 是否齐备？
- [ ] **中间叙事区**：分镜结构清晰，每镜 1-2 运镜，动作分肢体？
- [ ] **结尾权重区**：视觉风格收束 + 画质参数 + 约束四件套 + 时长比例 是否齐备？

### 最终审查

- [ ] **无模糊词**：是否删除了所有"好看的"、"高级的"、"有感觉"、"氛围感"、"电影感" 这类无法量化的模糊描述？
       ⛔ "电影感" → ✅ "逆光 + 金色轮廓光 + 暖饱和色调 + 浅景深 + 35mm 胶片颗粒"
- [ ] **无符号噪声**：是否清除了 `→` `--` `~` 等符号？用自然语言或"先...再...最后..."串接 beat
- [ ] **通读检查**：通读一遍，想象自己是 AI，能否毫无歧义地执行这些指令？
- [ ] **歧义断句**：多人场景是否用字母编号（美女C/美女D），避免"美女3 位"被误读为数量？（V-15）
- [ ] **参数中文化**：时长是否用"秒"而非"s"？比例是否明确？

### 五维体检（输出前最后一道关）

- [ ] **角色一致性（ID Stability）**：是否有大头照独立参考？是否反双胞胎？
- [ ] **画面稳定性**：是否有反变形约束？动作是否连贯？
- [ ] **镜头语言符合度**：景别 + 运镜是否每镜单独标注？
- [ ] **风格与约束执行度**：风格词单一？反字幕 / 反 logo？
- [ ] **多模态绑定**：每个 `[图N]/[视频N]/[音频N]` 的角色都明确？

> 任意一维有 ❌ → 回到对应章节修复，再交付。
> 五维全部 ✅ → 输出 prompt 并附上"素材输入顺序"使用说明。

## 速查：常见缺漏排查口诀

> **"一首一尾两不漏，剧组排队按顺投，肢体光源带数字，反字反水反双胎"**

- **一首**：开头权重区（素材定义 + 主体 + 风格）
- **一尾**：结尾权重区（画质 + 约束 + 时长）
- **剧组排队按顺投**：素材按 prompt 出场顺序上传
- **肢体光源带数字**：动作细化到肢体、光源具名、时长用"秒"
- **反字反水反双胎**：反字幕 / 反水印 logo / 反双胞胎（+ 反变形）
