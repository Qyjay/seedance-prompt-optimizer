# 第一人称视角（POV / FPV / Orb）专章

第一人称是 Seedance 2.0 中**最容易翻车**的镜头类型。模型默认会"漂"回浮空的第三人称跟拍。
本章给出在公网实测中被验证过的稳定写法，命中以下任一信号词都应优先回到本章：

> "第一人称 / 主观镜头 / POV / FPV / 沉浸视角 / GoPro / 行车记录仪 / 戴眼镜看出去 / 玩家视角"

⚠️ **不要直接写"第一人称视角"**单独出现。这个词在 Seedance 训练语料里语义模糊，模型有时会把它理解为"角色面对镜头说话"，结果给你一个对着镜头的人。必须改成下面三种**有明确锚点的子类型**之一。

---

## 一、三种子类型与各自的关键词

| 子类型 | 适合的画面 | 必写关键词 |
|---|---|---|
| **POV 主观镜头** | 角色"我"看出去：开车看路、走路看脚、伸手拿物、第一人称玩游戏 | "主观镜头 / POV"+ 命名设备 + 肢体锚点 |
| **FPV 穿越机视角** | 高速穿梭、连续穿越多个空间、跑酷、滑雪、穿楼 | "FPV 穿越机视角，连续穿越 A→B→C，速度极快" |
| **Orb 单镜连续 POV** | 一镜到底的第一人称动作戏（角色拿着相机打怪、施法、奔跑 15 秒） | "单镜连续第一人称 POV，相机就是她的眼睛" |

> Orb 是 Higgsfield 实测命名的格式（"the camera IS her eyes"），实际是"POV + 一镜到底 + 角色驱动"的复合形式，单独抽出来是因为它的稳定模板差异较大。

---

## 二、POV 六要素骨架（核心方法论）

来源：VIDEO AI ME 创始人 Paul Grisel 的 Seedance 2.0 POV 实测博客。**六要素缺一即漂**。

```
[1 命名摄像机身份] + [2 画面内的肢体锚点] + [3 三个感官化环境细节]
+ [4 按 beat 分段的动作] + [5 命名光源 + 配色锚点] + [6 反向约束]
```

### 1. 命名摄像机身份（必写）

不能只写 "POV shot / 第一人称视角"。**必须命名具体设备**，否则模型不知道用什么镜头语言：

| 设备 | 触发的画面特征 |
|---|---|
| iPhone 前置摄像头 / iPhone 自拍模式 | 手机自拍构图、轻微手持抖动 |
| iPhone 竖向手持 | 9:16 竖屏自然手持感 |
| GoPro 胸挂 / GoPro 头戴 | 鱼眼畸变、低角度、身体颠簸 |
| 行车记录仪 / dashcam | **锁死机位、不抖动**、轻微果冻效应 |
| 头顶俯拍 iPhone（厨房料理常用）| 顶视固定俯拍，双手从画面下方进入 |
| 无人机 FPV 穿越机 | 高速穿越，无切镜，沉浸感 |
| 第一人称游戏视角 | 屏幕边缘的 HUD、武器/手部位于下方 |

### 2. 画面内的肢体锚点（必写，最重要）

> **这是 POV 与第三人称的唯一物理区分**。如果画面里没有"我"的身体局部，模型 90% 会回退到第三人称。

常用锚点：

- **双手**：从画面下方/侧方伸入，握杯子、方向盘、手机、武器、刀
- **双脚 / 鞋尖**：低头看脚走路、跑步、滑板
- **小臂**：高举手机录制、伸出手指
- **躯干边缘**：肩膀、胸前的衣领、背包带
- **道具锚定**：枪管、画笔、手电筒光束、方向盘

写法范式：

```
左手从画面下方进入，五指扣住一只白色陶瓷马克杯
两只手出现在画面底部握住皮革方向盘
鱼眼画面下沿可见胸前战术背心的肩带与持枪小臂
```

### 3. 三个感官化环境细节（建议写）

不要只写"在咖啡店"。给三个具体可视的细节：

```
✗ 在咖啡店里
✓ 木质长桌、桌上一支倒影窗光的玻璃水杯、远处磨豆机蒸汽
```

### 4. 按 beat 分段的动作（必写）

> "POV works best with one or two beats per second. Cramming five beats into a four second clip makes the motion feel rushed and fake." —— [1]

5 秒视频 ≤ 5 个 beat，4 秒视频 ≤ 3 个 beat。每个 beat 写一个清楚的动作，不要堆。

```
beat 1: 左手伸入画面握住马克杯 →
beat 2: 抬起马克杯靠近镜头 →
beat 3: 微倾杯身后放回木桌
```

### 5. 命名光源 + 配色锚点（建议写）

POV 没有光源会渲染得"灰平"。命名一个具体光源：

```
柔和暖色窗光从镜头左侧打入，背后从破窗透进冷蓝色边光，
配色：奶油色、燕麦色、胡桃棕。
```

### 6. 反向约束（必写）

POV 是字幕、logo、stock 音乐高发场景。结尾固定写：

```
保持无字幕，不要生成 logo，不要生成水印。
```

如果是 Orb 长 POV 动作戏，再加一句明确镜头不做什么（[2] 关键技巧）：

```
单镜连续，无切镜、无变焦、自然头部晃动。
```

## 三、五个稳定 Recipe（按场景套用，已通过公网实测）

以下五个模板来源于 [1] VIDEO AI ME，已被翻译并按 Seedance 2.0 中文规范重写。

### Recipe 1 · 晨间 POV（生活 / 美妆 / 饮品广告）

```
主观镜头 POV，iPhone 前置摄像头由一位 20 多岁女性平举至眼平视高度。
她位于布鲁克林公寓，晨光透窗。
beat 1：左手从画面下方进入，五指扣住一只白色陶瓷马克杯，杯里是黑咖啡；
beat 2：她将马克杯举近镜头微倾；
beat 3：把杯子放回画面右下角的木质边桌上，旁边有一棵小琴叶榕。
柔和暖色窗光从镜头左侧打入，背后透过裂缝玻璃透进冷蓝色边光。
配色：奶油色、燕麦色、胡桃棕。
画质如真实 iPhone 自拍，轻微手持呼吸感，阳光中可见浮尘颗粒。
保持无字幕，不要生成字幕，不要生成 logo，不要生成水印。
时长：5秒，比例：9:16
```

### Recipe 2 · 滑板场 FPV/POV（运动 / 鞋服）

```
主观镜头 POV，GoPro 胸挂在一名滑手身上，他正在金色夕阳的混凝土滑板碗中滑行。
画面下沿可见滑手两只松松垂下的双手与随节奏弯曲的膝盖。
beat 1：地面在动态模糊中飞掠；
beat 2：碗沿出现在画面下方；
beat 3：相机随起跳猛烈上仰，板子 ollie 离地；
beat 4：空中悬停一拍；
beat 5：落地一声闷响。
暖色夕阳逆光，轻微镜头眩光。
配色：琥珀、混凝土灰、牛仔蓝。
画质如真实胸挂 GoPro：鱼眼畸变、画面边缘弯曲、轻微弹跳震动。
保持无字幕，不要生成 logo，不要生成水印。
时长：5秒，比例：9:16
```

### Recipe 3 · 厨房俯拍 POV（美食 / 厨具 / 食材）

```
主观镜头 POV，iPhone 头顶悬挂俯拍正下方的木质砧板。
beat 1：两只手从画面下方进入，左手扶住一颗成熟红番茄，右手握主厨刀；
beat 2：刀切番茄分三片，每一片倒下平贴砧板；
beat 3：左手将三片番茄推入旁边的不锈钢碗中。
顶部暖色吊灯主光，画面外锅中升起轻微蒸汽。
配色：番茄红、橡木棕、拉丝钢。
画质如 iPhone 拍摄，即便是固定挂载也保留细微手持微抖，旁边玻璃杯有冷凝水珠。
保持无字幕，不要生成 logo，不要生成水印。
时长：5秒，比例：16:9
```

### Recipe 4 · 行车 POV（汽车 / 出行 / 配送）

```
主观镜头 POV，行车记录仪安装在挡风玻璃内侧，黎明时分车辆驶过安静住宅街。
画面下沿是两只手放在皮革方向盘上。
beat 1：方向盘缓慢左打，车驶向路口；
beat 2：方向盘回正；
beat 3：前方人行道一名晨跑者横穿，车温和减速。
冷色黎明蓝光，路边树丛之间漂着低雾。
配色：石板蓝、沥青灰、柔白。
画质如真实行车记录仪：固定锁死机位，无任何抖动，路旁树梢有轻微果冻效应。
保持无字幕，不要生成 logo，不要生成水印。
时长：5秒，比例：16:9
```

### Recipe 5 · 演唱会 POV（音乐 / 文娱 / 直播）

```
主观镜头 POV，一位粉丝在夜晚拥挤的演唱会人群中竖向高举 iPhone 拍摄。
画面右下方可见持机的手臂与小臂，手机竖向。
画面中下部是上下涌动的人头与挥舞的双手；
舞台后方紫金光束节奏性脉冲。
beat 1：场外吉他 riff 响起；beat 2：人群欢呼；beat 3：拍摄者轻倾手机捕捉舞台中央的歌手剪影。
舞台聚光，洋红与琥珀光，配色：洋红、金、深海军蓝。
画质如真实 iPhone 竖拍，受人群拥挤的轻微上下晃动，镜头收到舞台灯眩光。
保持无字幕，不要生成 logo，不要生成水印。
时长：5秒，比例：9:16
```

## 四、Orb（一镜到底动作 POV）模板

适用：第一人称魔法/格斗/冒险戏，画面中"我"的双手始终在画面下沿，连续 10–15 秒不切镜。
来源：[2] Higgsfield 的 "Orb" 格式实测。

```
单镜连续，主观镜头 POV，相机就是「主体1」的眼睛。
极度颠簸的手持运动，完全不稳定，剧烈的真实人体动作，
持续微抖、激烈摇头、突兀颠簸、频繁过度旋转后硬性回正，
偶尔近乎运动模糊失焦，全程无任何稳定，
广角镜头（强畸变），画面边缘有轻微色散，
她的双手始终出现在画面下沿。
（动作描述：……按 beat 写动作，VFX 用方括号写：[VFX：……]）
无背景音乐，仅原始 SFX。
电影级布光、写实质感、35mm 胶片质感、明显胶片颗粒、
锐利但不完美的对焦、可见的对焦呼吸、快速动作时的运动模糊、
高光泛光、轻微低饱和、ARRI ALEXA 美学，
实拍特效感、最少 CGI 感、自然瑕疵。
单镜连续，无切镜、无变焦、自然头部晃动。
保持无字幕，不要生成 logo，不要生成水印。
时长：15秒，比例：16:9
```

> Orb 模板是高难度生成，建议先在 5 秒短镜上跑通节奏再扩展到 15 秒。

## 五、POV 六大常见错误（来自实测）

| # | 错误写法 / 症状 | 修复 |
|---|---|---|
| 1 | 只写"第一人称视角"被理解为面对镜头说话 | 改成 "主观镜头 POV，相机就是「主体1」的眼睛"，并显式说"画面中不出现「主体1」本人" |
| 2 | 没写肢体锚点，画面漂回第三人称跟拍 | 在 prompt 前部加"画面下沿可见双手 / 双脚 / 方向盘 / 持枪小臂" |
| 3 | 摄像机身份只写 "POV shot" 太抽象 | 改成具体设备名：iPhone 前置 / GoPro 胸挂 / 行车记录仪 / 无人机 FPV |
| 4 | 5 秒里塞了 8 个 beat，画面快进、糊脸 | 严格限制 1–2 beat/秒；5 秒视频 ≤ 5 beat |
| 5 | 没命名光源，画面"灰平" | 必加一句"窗光从左 / 舞台灯 / 路灯 / 黎明天光"等 |
| 6 | **过度描写主角的脸** | POV 中"观众就是这张脸"，**不要描述主角面部特征**，只描写他的手、脚、身体局部 |

> 错误 6 是中文创作者最常踩的坑：习惯性地写"主角是穿西装的男人，长方脸、剑眉、薄唇"——这些描写在 POV 里会触发模型把脸渲染到镜头前，破坏第一人称感。POV 中主角的视觉表达是**他能看到什么**，不是**他长什么样**。

## 六、与第三人称的并用

业务允许时，可以在多镜头视频里**穿插一个 POV 镜头**作为节奏调剂：

```
镜头 1：第三人称中景跟拍主体1 走入巷子，回头张望。
镜头 2：切到主观镜头 POV，画面下沿可见主体1 的双手缓缓从腰间拔枪，
        前方巷子尽头有一道阴影晃动。
镜头 3：切回第三人称过肩镜头，主体1 持枪向前推进。
保持无字幕，不要生成 logo，不要生成水印。
时长：8秒，比例：16:9
```

⚠️ 多镜头中如果包含 POV，**强制使用 16:9**。竖屏 POV 字幕和胡言乱语率显著更高（参考 V-2、V-11）。
