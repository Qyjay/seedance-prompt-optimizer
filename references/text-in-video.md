# 视频中的文字生成

Seedance 2.0 在 T2V / I2V / R2V / V2V 等场景下都支持生成常用文字。模型可自动匹配风格颜色，也可在 prompt 中显式指定。

⚠️ **优先使用常用字，避免生僻字与特殊符号**，确保最佳呈现。

## 一、Slogan

**通用公式**：

```
「文字内容」+「出现时机」+「出现位置」+「出现方式」，「文字特征（颜色、风格）」
```

**示例**：

```
手绘漫画风格，三个人围坐在一起吃[图1]中的炸鸡，气氛友好愉悦，后画面逐渐模糊，画面中部文字"快乐尽在 Seedance"。
```

如果对文字表现效果有较严格要求，建议把目标文字风格做成 logo 图作为参考输入。

## 二、字幕

**公式**：

```
画面底部出现字幕，字幕内容为"……"，字幕需与音频节奏完全同步。
```

**示例（画外音）**：

```
生成带有画外音的视频：一个深沉、平静的男声说："在宏大的宇宙中，我们的世界不过是一个短暂的瞬间。然而，在其中，生命不顾一切地繁荣。"场景应从夜晚缓慢过渡到黎明，星星逐渐消失，太阳从山后升起。画面底部按照台词出现字幕。
```

**示例（对话）**：

```
[图1]中的两人在办公室聊天，女性先说话，她说道：{你每次卡点到，是不是很享受这种刚刚好的感觉？}男性笑着回应：{我有我的节奏}。角色说话时，对话随意自然，画面底部出现对应台词字幕。
```

## 三、气泡台词

**公式**：

```
「角色」说："……"，角色说话时周围出现气泡，气泡里写着台词。
```

**示例**：

```
[图1]中的两人穿着运动服在学校的操场跑步，女孩看向男孩，自信地笑着说：{We can definitely do it!}切镜到男孩的近景，他犹豫地回答：{Are you sure?}镜头切回女孩的中近景，她语气轻快地说：{Yes!}情绪明亮而坚定。说话的角色周边出现气泡，气泡里面是对应台词。
```

## 四、避免生成字幕（V-2）

**典型现象**：本不该有字幕的视频，模型自作主张生成字幕，且文字常有错误。

**修复（无法 100% 避免，只能降低出现概率）**：

1. **prompt 中加明确约束**：`保持无字幕，避免画面生成字幕`。可降字幕生成概率约 60%→30%。
2. **去除参考图/视频中的多余文字**：用 Seedream/Seedance 把素材中不必要的文字先擦除。
3. **改为横屏输出**：竖屏比横屏更容易出字幕。改为 16:9 后概率可降至 < 10%。
4. **减少分镜数**：一次生成视频中分镜越多，越容易出字幕。
5. **后期补救**：用 AI MediaKit 字幕擦除工具消除已生成的字幕。

## 五、字符规范（强制）

| 内容 | 符号 | 示例 |
|---|---|---|
| 音乐 | `（）` | `（背景中播放着快节奏的摇滚乐）` |
| 音效 | `<>` | `<远处传来狗叫声>` |
| 台词 | `{}` | `{你好，世界}` |
| 字幕 | `【】` | `【第一章：启程】` |

⚠️ 台词为小语种（非中英文）时，必须标注语种：

```
用日语说道{こんにちは}
用韩语说{아빠, 배고파요!}
```

## 六、参数

```
时长：4秒，比例：9:16
```

- **必须用中文"秒"**，不能写"s"或"seconds"。
- 时长和宽高比建议放在 prompt 最前面或最后面。
- 接口已传参时，prompt 里仍可重复一次以稳定结果。
