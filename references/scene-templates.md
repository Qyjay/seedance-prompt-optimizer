每个行业附 1–3 个可直接复用 / 改写的范式 prompt。详见 Doubao-Seedance-2.0 企业级业务场景指南。

## 一、电影影视

### 1. 无缝多镜头切换

```
镜头 1：中景平视，主体1 推开木门走进酒馆，门轴吱呀作响。
镜头 2：跟拍主体1 走向吧台，背景人群虚化，景深浅。
镜头 3：近景仰拍，主体1 抬头看向二楼，眼神锐利。
镜头 4：特写，主体1 的手按在腰间剑柄上。
（背景中播放着低沉的西部口琴 BGM）
风格：电影级渲染，高对比度，胶片颗粒感。
保持无字幕，避免画面生成字幕；不要生成 logo，不要生成水印。
时长：6秒，比例：16:9
```

### 2. 一镜到底（长镜头）

```
一镜到底长镜头，无切镜。
主体1 从教学楼一楼大厅出发，镜头跟拍其上楼梯、穿过走廊、推开教室门、走到讲台前转身面对镜头。
全程平视跟拍，节奏自然连贯。
风格：2D 日漫风格，新海诚清新治愈光影，浅景深。
（背景中播放着轻柔的钢琴曲）
时长：10秒，比例：16:9
```

### 3. 微表情

```
特写镜头，平视固定机位，主体1 的面部占满画面。
镜头 1：主体1 眼睑微垂，嘴角紧抿，眉头几不可察地皱起 0.5 秒。
镜头 2：眼神突然抬起对视镜头，瞳孔微微放大，嘴角缓慢上扬到一个克制的微笑。
风格：电影级渲染，胶片颗粒感，浅景深。
保持无字幕。
时长：5秒，比例：16:9
```

### 1. 古装仙侠剧片头

```
3D 国漫 CG 仙侠风格。
镜头 1：大远景俯拍，云海翻腾，主体1（白衣仙人，参考[图1] 面部、[图2] 妆造）立于山巅。
镜头 2：抽离式后拉运镜，从主体1 的面部特写持续后拉，揭示其身后的仙宫与漫天星辰。
镜头 3：剑光突起，主体1 拔剑出鞘，配<金属出鞘的清脆声>。
（背景中播放着大气磅礴的国风交响 BGM）
```

### 2. 悬念式开篇

```
2D 日漫风格。
镜头 1：固定中景，主体1（少女）独自站在天台边缘，背对镜头，长发被风吹起。
镜头 2：希区柯克变焦（Dolly Zoom），主体1 大小不变，但身后的城市背景剧烈拉伸变形。
镜头 3：主体1 缓慢转头，库布里克对称凝视镜头，眼神凝视镜头底部。
（背景音乐由轻柔逐渐升起紧张感）
画面底部字幕：【那一天，我决定不再隐瞒。】
时长：6秒，比例：9:16
```
