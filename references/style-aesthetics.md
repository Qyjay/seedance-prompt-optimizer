# 风格美学词典

风格关键词必须明确，否则极易被参考图带偏成写实风格（V-4：风格漂移）。

## 一、动画 / 游戏风格

| 关键词 | 适用 |
|---|---|
| 2D 日漫风格 | 日系手绘动画 |
| 3D 国漫 CG 仙侠风格 | 国漫修仙、玄幻 |
| 皮克斯 3D 动画 | 角色饱满、卡通可爱 |
| 迪士尼 3D 动画 | 童话、奇幻 |
| 新海诚清新治愈风 | 城市光影、青春 |
| 吉卜力风格 | 自然、温暖、手绘 |
| 粘土动画 | 手作质感、定格风 |
| 毛毡动画 | 温暖、织物质感 |
| 水墨风格 | 中国风、留白 |

## 二、电影 / 时期风格

| 关键词 | 适用 |
|---|---|
| 电影级渲染 | 提升画质感 |
| 王家卫风格 | 高对比、霓虹、慢镜 |
| 韦斯·安德森风格 | 对称构图、低饱和度 |
| 巴洛克风格 | 华丽、戏剧光影 |
| 京剧风格 | 中式舞台、脸谱 |
| 90 年代港风 | 复古胶片质感 |
| 赛博朋克 | 霓虹、未来都市 |

## 三、光影 / 色彩

| 关键词 | 适用 |
|---|---|
| 暖色调 | 温馨、治愈 |
| 冷色调 | 悬疑、科技 |
| 高对比度 | 戏剧化、强冲击 |
| 低饱和度 | 文艺、复古 |
| 黑白 | 经典、严肃 |

## 四、视觉效果

| 关键词 | 适用 |
|---|---|
| 高清 / 4K / 超写实 | 画质提升 |
| 慢镜 / 高速摄影 | 强情绪 |
| 景深虚化（浅景深） | 突出主体 |
| 胶片颗粒感 | 复古质感 |
| 镜头光晕（Lens Flare） | 阳光通透感 |

## 五、风格组合范式

```
[风格类别1] + [光影色彩] + [视觉效果]
例：3D 国漫 CG 仙侠风格 + 暖色调 + 电影级渲染
例：2D 日漫风格 + 高对比度 + 慢镜
例：粘土动画 + 暖色调 + 浅景深
```

## 风格漂移修复（V-4）

**典型现象**：参考图风格偏写实，或多张参考图混用偏写实图片，没有强调风格保持时，模型容易生成偏写实风格。

**修复**：

1. 把**参考图**预先用 Seedream 等转成目标风格，再用风格化后的图片生视频。
2. prompt 中**明确写**："3D 国漫 CG 仙侠风格"或"2D 日漫风格"等。
3. 涉及多张图时，写"整体风格保持 [目标风格]"。
