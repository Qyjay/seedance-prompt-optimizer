# 视频编辑：增删改 / 延长 / 轨道补齐

Seedance 2.0 支持元素增删改、向前向后延长、轨道补齐三类编辑能力。

⚠️ 涉及视频时，**按上传顺序使用 `[视频1] / [视频2] / [视频3]`**。

⚠️ 在编辑和延长任务中，**不要写"参考视频 N"**，直接写`[视频N]`，否则会被误识别为参考任务。

## 一、元素增删改

### 增加元素

**句式**：

```
在[视频N] 的[时间位置]+[空间位置]，增加[理想元素描述]
```

**示例**：

```
[视频1]，在台面上添加炸鸡、披萨等小吃。
```

### 删除元素

**句式**：

```
删除[视频N] 中的[被删除元素]，视频其他内容保持不变
```

**示例**：

```
清除[视频1] 桌面上的其他零件和工具，保持桌面整洁干净，桌面上只有他俩手里的。
```

### 修改元素

**句式**：

```
将[视频N] 中的[被更换元素描述]，替换为[理想元素描述]
```

**示例**：

```
将[视频1] 中的香水替换成[图1] 中的面霜，动作和运镜不变。
```

## 二、向前 / 向后延长

**句式**：

```
向前/向后延长[视频N] + [需延长的视频描述]
```

或：

```
生成[视频N] 之前/之后的内容 + [需延长的视频描述]
```

**示例（向后延长）**：

```
生成[视频1] 之后的内容，迟到的两个男士跑向他们，五个人终于见面，友好聊天。
```

**示例（向前延长）**：

```
向前延长[视频1]，给白衣男子过肩镜头，白衣男子说{It's not that bad. You're just stressed. Everyone goes through this, you just need to keep going.}
```

⚠️ **画质劣化（V-8）**：把模型生成的视频再次延长，画质会逐次劣化叠加，尤其在人脸会出现斑驳色块。

**修复模板**：

1. 把原始视频用 Seedance 2.0 转化为**白模视频**：

```
将[视频1] 转化为白模视频：保留所有人物的姿态和动作，但移除所有纹理、色彩、面部细节，仅保留白色 3D 几何模型，背景纯白。
```

2. 用白模视频 + 高清人物图 + 高清场景图作为输入：

```
向前延长[视频1]（白模视频），人物形象严格参考[图1]（高清人脸特写），场景参考[图2]（高清场景图），生成 [新内容]。
```

## 三、衔接处跳变（V-6）

**典型现象**：用"延长模式"生成的视频拼接后，在衔接处出现画面跳变、回退。

**修复**：

- **后期剪辑修补**：对前段视频末尾删 6 帧，对后段视频开头删 1 帧。
- 或用**转场切镜**结尾，用切镜代替无缝衔接。

## 四、轨道补齐

**句式**：

```
[视频1] +[过渡画面描述]+ 接[视频2] +[过渡画面描述]+ 接[视频3]
```

**限制**：

- 最多 3 段视频输入。
- **总时长不得超过 15 秒**。
- 模型自动截取首尾视频的衔接部分，仅保留必要片段参与合成。

**示例**：

```
[视频1]，树叶落地的瞬间，激起金色粒子特效，一阵风吹过，接[视频2]。
```

## 五、数字滚动特效（V-9）

**典型现象**：模型生成的数字滚动效果有明显无序跳变感，提示词约束无效。

**修复**：增加正确的数字滚动效果**参考视频**，模型生成的视频中数字滚动效果观感大幅提升。

```
参考[视频1] 的数字滚动特效，生成 [新场景] 中数字从 0 滚动到 100 的画面，保持滚动节奏一致。
```
