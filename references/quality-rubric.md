# 良品率五维衡量标准（Quality Rubric）

> 来源：火山引擎《Seedance 2.0 - PE 指南》。

## 核心理念

在 Seedance 2.0 的语境下，"**良品**"不是主观的"好看"，而是客观的"**符合预期**"。

prompt 写得"看起来很专业"没有意义；**唯一的衡量标准是最终视频在以下五个维度全部达标**。

一份"良品"视频必须**同时满足**以下五条：

## 五维标准

### 1. 角色一致性（ID Stability）

**定义**：视频中的核心角色，尤其是在多镜头切换时，面部、体型、服饰等关键特征无明显"漂移"或"变脸"，与参考图 / 视频保持高度一致。

**常见失败**：

- 角色 A 在镜头 1 是单眼皮，到镜头 2 变双眼皮
- 主角中途突然撞脸某明星
- 角色服饰颜色、配饰中途变化

**保障手段**：

- 人脸单独裁剪为大头照独立参考（V-1）
- 显式定义主体：`[图N]为角色"X"的外观参考,严格还原...`
- 多次出场重复角色名，禁止省略指代
- 多人场景使用字母编号避免歧义（V-15）

### 2. 画面稳定性（Frame & Motion Stability）

**定义**：无大幅度画面抖动、无规律性闪烁、无跳帧或卡顿。动作自然流畅、不僵硬、不穿模。

**常见失败**：

- 规律性闪烁横纹（V-5）
- 延长拼接处跳变（V-6）
- 多次延长后画质劣化（V-8）
- 动作不连贯，肢体穿模

**保障手段**：

- 结尾加约束：`面部稳定不变形、五官清晰、人体结构正常、动作自然流畅不僵硬、无卡顿、无闪烁`
- 动作描述按时间顺序、补充幅度速度
- 避免单点剧烈动作，改用渐进式动作
- 延长场景使用白模视频中转（V-8）

### 3. 镜头语言符合度（Camera Language Compliance）

**定义**：视频的景别（特写 / 中景 / 全景）、运镜（推 / 拉 / 摇 / 移 / 跟）与 prompt 指令精确匹配，叙事节奏符合预期。

**常见失败**：

- 写了"近景慢推"，结果是"中景固定"
- 写了"第一人称 POV"，结果是第三人称跟拍（V-12）
- 多镜头叙事节奏混乱

**保障手段**：

- 每镜只用 1-2 种运镜，新手首选"近景+慢推"或"中景+跟拍"
- 第一人称必须命名设备 + 肢体锚点（V-12）
- 段级时间轴分镜：`镜头1（0至5秒）/ 镜头2（5至10秒）`
- 复杂运镜提供参考视频锁定

### 4. 风格与约束执行度（Style & Constraint Adherence）

**定义**：画面整体风格（赛博朋克 / 复古胶片）、光影色调、画质参数严格遵循 prompt 设定。所有负向约束（无字幕 / 无 logo / 面部不变形）被有效执行。

**常见失败**：

- 要求 2D 动漫，结果偏真人写实（V-4）
- 强制反字幕，结果仍出现字幕（V-2）
- 出现非预期 B 站 / 芒果 TV logo（V-3）

**保障手段**：

- 风格关键词放开头，禁止混用（"复古"+"赛博朋克"）
- 极端精准风格控制：先用 Seedream 转风格，再图生视频
- 横屏优先：字幕概率明显低于竖屏
- 结尾约束四件套（反字幕 / 反 logo / 反双胞胎 / 反变形）

### 5. 多模态绑定准确性（Multi-modal Binding Accuracy）

**定义**：使用多模态参考时，模型能准确理解并执行每个素材（[图1] / [视频2] / [音频3]）被分配的角色（角色锚定 / 场景定调 / 运镜参考 / 节奏氛围）。

**常见失败**：

- 音频 1 是角色 X 的音色，结果被用到角色 Y 身上（A-3 串台）
- 视频 1 用于运镜参考，结果模型把画面内容也复刻了
- 多张图角色定义混淆

**保障手段**：

- 素材按 prompt 中出场顺序上传
- 第一次出现就显式定义素材角色（外观 / 道具 / 场景 / 音色 / 运镜）
- 音色绑定用专属句式：`[音频N]为角色"X"的专属音色参考,本视频中所有由X发出的台词必须严格使用[音频N],禁止用于其他角色`
- 单次素材总量 ≤ 4–5 个（V-18）

## 五维体检表（每次输出 prompt 前对照）

| 维度 | 是否达标 | 风险点 | 修复手段 |
|---|---|---|---|
| ID 稳定 | ✅ / ⚠️ / ❌ | （命中哪条 V-1 / V-7 / V-15） | （对应 references） |
| 画面稳定 | ✅ / ⚠️ / ❌ | （命中哪条 V-5 / V-6 / V-8） | |
| 镜头合规 | ✅ / ⚠️ / ❌ | （命中哪条 V-12 / 运镜不清） | |
| 风格约束 | ✅ / ⚠️ / ❌ | （命中哪条 V-2 / V-3 / V-4） | |
| 多模态绑定 | ✅ / ⚠️ / ❌ | （命中哪条 A-3 / V-13 / V-18） | |

> **核心原则**：五维全部 ✅ 才算"良品"。任何一维 ❌ → 必须就地修复后再交付。

## 抽卡建议

即便 prompt 写得再好，单次生成也未必次次良品。建议：

- 重要素材抽卡 3–5 次取最佳
- 仍未达标 → 调整 prompt 中的弱项维度，再抽 1–2 次
- 5 次仍未达标 → 走 `references/escalation.md` 联系 CSM
