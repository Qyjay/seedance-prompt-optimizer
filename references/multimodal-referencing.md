# 多模态参考与主体定义

Seedance 2.0 同时支持：**0–9 张图片 + 0–3 段视频 + 0–3 段音频** 作为参考。

## 指代格式（强制）

- 图片：`[图1] / [图2] / … / [图9]`
- 视频：`[视频1] / [视频2] / [视频3]`
- 音频：`[音频1] / [音频2] / [音频3]`

⚠️ **如对素材顺序有要求，必须按顺序上传**，prompt 中按上传顺序使用 `[图N]`。

⚠️ **使用 Asset 库时，依然要用"图1、视频1"指代主体，模型不会自动把 Asset ID 与输入素材对应上。**

## 主体定义（必做）

涉及任何参考素材中的角色 / 道具 / 场景，**第一次出现就要显式定义**。

### 角色外观定义句式

```
[图N]为角色"角色名"的外观参考,严格还原[特征列表]
```

核心特征要求：使用 **2–3 个清晰、稳定的静态特征**（服饰、发型、外观、类别），确保唯一可识别性。

**示例**：

```
[图2]为角色"爱豆"的外观参考,严格还原棕色毛绒质感、大眼圆脸、红色背带短裤+白T恤+橙色帆布鞋。
[图3]为角色"卡皮皮"的外观参考,严格还原黄色毛绒质感、绿叶头饰、黄色斜挎带、手持胡萝卜。
```

### 道具/场景定义句式

```
[图N]为关键道具"道具名"参考,严格还原[特征列表]
[图N]为[场景类型]场景参考,严格还原[空间/氛围特征]
```

**示例**：

```
[图4]为关键道具"嗨皮表"参考,严格还原红色方形表盘、红色硅胶表带、屏显10:08。
[图1]为儿童卧室场景参考,严格还原空间布局、家具陈设、暖色调与清晨柔光氛围。
```

### 音频音色绑定句式

> **核心原则**：参考音频 + 文字描述双重锁定，缺一不可。参考音频质量不足时，文字描述是模型二次校准的唯一依据。

```
[音频N]为角色"角色名"的专属音色参考（音色特征描述：如憨厚带点鼻音的男童声），
本视频中所有由角色名发出的台词,必须严格使用[音频N]的音色合成,禁止用于其他任何角色。
```

**音色特征描述必须包含以下至少三项**：

| 维度 | 示例词 |
|---|---|
| 性别 | 男声 / 女声 |
| 年龄感 | 5-7岁童声 / 20岁少女 / 30岁成年男性 |
| 声音质感 | 稚嫩透亮 / 憨厚带鼻音 / 温柔偏低沉 / 活泼明亮 / 沙哑磁性 / 清脆甜美 |
| 情绪基调（可选） | 温暖亲切 / 俏皮可爱 / 沉稳干练 |

**示例（带音色描述）**：

```
[音频1]为角色"爱豆"的专属音色参考（活泼稚嫩的男童声，音调偏高、透亮有弹性），
本视频中所有由爱豆发出的台词,必须严格使用[音频1]的音色合成,禁止用于其他任何角色。

[音频2]为角色"卡皮皮"的专属音色参考（憨厚带点鼻音的男童声，语速稍慢、低沉圆润），
本视频中所有由卡皮皮发出的台词,必须严格使用[音频2]的音色合成,禁止用于其他任何角色。
```

**画内台词也应在括号中附带音色描述辅助校准**：

```
爱豆(画内,活泼稚嫩男童声,音色严格使用[音频1],禁止偏离[音频1]):{走呀!}
卡皮皮(画内,憨厚带鼻音男童声,音色严格使用[音频2],禁止偏离[音频2]):{别忘带上你的嗨皮表~}
```

### 画内台词句式

角色在镜头内说话时，使用以下格式将音色绑定与台词紧密耦合：

```
角色名(画内,音色严格使用[音频N],禁止偏离[音频N]):{台词内容}
```

**示例**：

```
爱豆(画内,音色严格使用[音频1],禁止偏离[音频1]):{走呀!}
卡皮皮(画内,音色严格使用[音频2],禁止偏离[音频2]):{别忘带上你的嗨皮表~}
```

### 画外音台词句式

角色不在镜头内时，使用以下格式：

```
角色名(音色描述,画外):{台词内容}
```

无参考音频的角色须注明"模型合成,不使用任何参考音频"：

```
妈妈(30岁温柔女声,模型合成,不使用任何参考音频,画外):{去超市帮我买菜!}
"我"(5-7岁真实小朋友童声,模型合成,不使用任何参考音频,画外):{来了!}
```

### 多主体场景

存在多个主体时，分别定义并使用角色名区分：

```
[图2]为角色"爱豆"的外观参考,严格还原棕色毛绒质感、大眼圆脸、红色背带短裤+白T恤+橙色帆布鞋。
[图3]为角色"卡皮皮"的外观参考,严格还原黄色毛绒质感、绿叶头饰、黄色斜挎带、手持胡萝卜。
```

角色名要具备唯一性与稳定性，后续描述持续使用对应角色名，避免指代混乱。

### 三条铁律

1. **每次涉及主体都要明确指代**，避免省略（每次出现主体就提一次角色名）。
2. **描述简洁，避免冗余**；同一主体不能出现矛盾特征（语义冲突）。
3. **空间关系优先用参考图表达**，减少复杂文字描述。

## 句式模板速查

### 图片参考

| 用途 | 句式 |
|---|---|
| 主体多视角 | `参考/提取/结合 @图片N 中的[主体]，生成[画面描述]，保持[主体]特征一致` |
| logo 参考 | `…画面中出现 @图片N 的 logo，整体风格…` |
| 多主体 / 多元素参考 | `参考/提取/结合 @图片N 中的[元素]，生成[画面描述]` |
| 多宫格分镜图 | `场景设定在 @图片4 的餐厅内……@图片1 的女孩身着 @图片2 中的服装……` |
| 分镜图参考 | `参考 @图片1 中的分镜图，[各分镜按顺序出现]，之后[新内容]` |

### 视频参考

| 用途 | 句式 |
|---|---|
| 动作参考 | `参考 @视频N 的[动作描述]，生成[画面描述]，保持动作细节一致` |
| 运镜参考 | `参考 @视频N 的[运镜描述]，生成[画面描述]，保持运镜一致` |
| 特效参考 | `参考 @视频N 的[特效描述]，生成[画面描述]，保持特效一致` |

### 音频参考

```
参考 @音频N 中的[音色特点描述]，生成 [台词内容]
```

⚠️ 生成视频的台词风格和参考音频风格越接近，音色稳定性越高（A-3）。

## ID 漂移修复（V-1）— 关键

**触发条件**：用户给的人物参考图是三视图、全身图，且人脸占比小。

**修复模板**：

1. 把人脸区域**单独裁剪**为一张特写图，作为独立参考图（即使别的图也包含同一人）。
2. 把这张人脸特写图放在 prompt 引用顺序的**最前面**。
3. 在主体描述里**分层指代**：

```
主体1的面部特征参考 @图片1（大头照），妆造参考 @图片2（全身照）
```

⚠️ **不建议使用三视图或多视图作为人物参考。** 一张精准的人脸特写 + 一张全身/妆造图就够。

## 双胞胎修复（V-7）

涉及单人参考时，加上：

```
视频全程不要在同一画面中复制相同人物，不要多人同脸。
```

并精简 prompt、避免多视图。

## 多人参考（V-10）

参考人物超过 4 人会不稳定。修复：先用图模型（如 Seedream）生成多张图，每张人数 ≤ 4，再用这些图生视频。
